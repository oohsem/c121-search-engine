# c121-search-engine

## Project 3 dependencies and code reuse

- Beautiful Soup parses HTML. NLTK provides Porter stemming.
- The team builds the file-based index and retrieval code. No text-indexing
  library or database is required.
- The handout allows code from previous assignments. Project 3 implementation
  code must come from our team.
- Implement the bonus algorithms in this repo. Use the handout's permitted
  GUI libraries and summarization integrations.

Run the repair checks with `PYTHONPATH=src python -m unittest discover -s tests`.
